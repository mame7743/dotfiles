# UI/UX デザインスキルの追加

- date: 2026-10-07
- status: decided
- related: skills/ui-ux-pro-max, skills/web-design-guidelines, skills/frontend-design, install.sh

## Context（背景）

UI/UX デザイン支援のスキルを増やしたいという要望。候補は3つ:

| スキル | 用途 |
|---|---|
| UI UX Pro Max | 配色・文字・UIパターン・UXルール検索とデザインシステム生成 |
| Frontend Design (Anthropic) | 画面の新規作成・見た目改善 |
| Web Design Guidelines (Vercel) | 実装後のアクセシビリティ・操作性レビュー |

## Decision / Finding（決定・発見）

- `frontend-design` は既に `skills/frontend-design` として管理・配布済みだったため変更なし。
- `ui-ux-pro-max` を追加。公式 `ui-ux-pro-max-cli@2.15.0` の
  `uipro init --ai opencode` 出力のうち **`ui-ux-pro-max` スキルのみ**を
  `skills/ui-ux-pro-max/` にベンダリング（3.5MB、MIT、`LICENSE` 同梱）。
  - 同梱されている Python スクリプトは標準ライブラリのみで自己完結。
  - CLI が同時生成する `design` / `design-system` / `brand` / `ui-styling` /
    `banner-design` / `slides` は意図的に追加していない。
- `web-design-guidelines` を追加（Vercel、`SKILL.md` は上流のまま）。
  上流リポジトリに LICENSE が無い点は `SOURCE.md` に明記。
- 配布は既存の `install.sh` と同方式（`skills/*` を
  `~/.config/opencode/skills`, `~/.claude/skills`, `~/.codex/skills`,
  `~/.agents/skills` へ symlink）。今回は手動で symlink を作成済み。
- 検証: `scripts/search.py` の `--design-system` / `--domain ux` /
  `--stack vue` を実行し、ローカルデータ参照が動作することを確認。
  OpenCode は両スキルを認識済み。

## 追加: design-dashboard（ローカル作成スキル）

- `~/Downloads/design-dashboard` のスキルを `skills/design-dashboard/` に追加。
- 内容: デジタル庁「ダッシュボードデザインの実践ガイドブック」を参考にした
  要件整理〜実装〜レビューの手順。`references/source.md`（出典・適用範囲）、
  `references/design-review.md`（独自の点検ルール）を同梱。
- 公式準拠・認証・全文反映を主張しない旨を `source.md` に明記。
- OpenAI/Codex 形式（`agents/openai.yaml`, `assets/icon.svg`）を含む。
  既存の `organize-codebase-structure` と同じ構成。
- 外部出典の逐語転載ではないため、ライセンス上の懸念は小さい。
