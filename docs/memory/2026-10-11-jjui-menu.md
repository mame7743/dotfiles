# jjui 日本語操作メニュー

- date: 2026-10-11
- status: decided
- related: config/jjui/config.lua, scripts/install.sh, scripts/install.ps1, README.md
- 環境: jj 0.46.0 / jjui 0.10.11（macOS, Homebrew）

## Context（背景）

jjui はキー操作が多く、コマンドを暗記しないと使えない。覚えるキーを1つに絞り、
日本語の操作一覧から選んで実行できるようにしたい。既存の jjui 設定は無かった。

## Decision（決定）

- jjui の Lua 設定 `config.lua`（`setup(config)`）で、`config.action` により
  アクション `open_menu` を定義し、キー **`m`**（scope `revisions`）へ束縛する。
- メニューは標準の `choose({ options, title, ordered })` ダイアログ。
  上下（↑↓ / k j）で選択、Enter 実行、Esc キャンセル、`/` で絞り込み。
- メニュー項目は「カーソル選択中のコミット（`[選択]`）」と「リポジトリ全体（`[全体]`）」を
  ラベルで区別。タイトルに `選択=<change_id>　@=<change_id>` を表示し両者を混同しない。
- 各項目は jjui の**ビルトインアクションを呼ぶだけ**で、独自に jj コマンドを組み立てない。
  実際の対象はソース（v0.10.11 `internal/ui/revisions/revisions.go`）で確認:
  - `[選択]`: `revisions.diff()`, `revisions.open_details()`, `revisions.describe()`,
    `revisions.new()`（選択コミットを親に新規）, `revisions.edit()`, `revisions.open_set_bookmark()`,
    `revisions.split()`, `revisions.open_squash()`, `revisions.open_rebase()`
  - `[全体]`: `jjui.ui.open_git()`（fetch/push は git ビューで選択）, `jjui.ui.open_undo()`,
    `jjui.ui.open_oplog()`
- 選択が無いとき、`[選択]` の項目は実行せず日本語で案内する。
- `force_*`（immutable 解除）や push は既定操作にしない。分割/統合/rebase は標準UIを維持。
- 保存: `config/jjui/config.lua` を dotfiles 管理下に置き、`~/.config/jjui/config.lua` へ
  **ファイル単位**で symlink（jjui が同ディレクトリへ `types.lua`/`.luarc.json` を生成するため、
  ディレクトリ全体リンクは避ける）。

## 仕様確認（推測しない）

- `jjui -install-lua-types` が生成する `~/.config/jjui/types.lua`（v0.10.11 生成）で API を確認。
- `choose(...)` は文字列を返す（キャンセル時 nil）。`config.action(name, fn, {key,scope,desc})`
  はソース `internal/scripting/config.go` で確認。
- `config.lua` の読み込みは `internal/config/loader.go` の `LoadLuaConfigFile`（v0.10.11）。
- `context.change_id()` は**最短一意プレフィックス**を返す（例: "u"）。表示用に
  `jj log -r <prefix> -T 'change_id.short()'` で12文字へ解決している。

## Verification（検証）

一時リポジトリで PTY 経由で起動し確認（実リモートへの push は未実行）:

- `m` でメニューが開き、日本語12項目とタイトル（選択/`@`）が表示される。
- コミット選択を `@`→親へ移すとタイトルの `選択=` が変わる（`u`→`o`、解決後12文字）。
- Esc キャンセルで oplog が変化しない（無変更）。メニューも閉じる。
- 先頭項目（差分）実行で Lua エラーが出ない。
- squash / rebase を開いて Esc → oplog 無変更（標準UIが開く、force なし）。
- フィルタで「jj edit」を選んで実行 → `@` が選択コミットへ移動（対象が正しいことを実証）。
- revset `none()`（行なし）ではタイトルが `選択=なし` になり、`[選択]` 実行時に日本語案内が出て実行されない。
- `[全体]` の git ビューは選択なしでも開ける。

## Revert（元に戻す）

- `rm ~/.config/jjui/config.lua`（symlink を削除）でメニューは無効化される。
  既存ファイルは無かったため他に戻すものはないが、`~/.config/jjui.backups/jjui-<ts>/` に退避済み。

## 残るリスク・前提

- Windows は `%AppData%\jjui\config.lua` へリンク（実機未検証）。
- jjui の将来版で Lua API / ビルトイン名が変わる可能性（0.10.x 前提）。
