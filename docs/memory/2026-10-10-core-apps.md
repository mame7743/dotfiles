# 最低限のアプリ（core プロファイル）の定義と導入

- date: 2026-10-10
- status: superseded
- superseded-by: 2026-10-11-core-environment
- related: deps/core.txt, install-deps.sh, Makefile, deps/check.sh, bootstrap.sh, docs/dependency-policy.md, README.md

## Context（背景）

依存管理は「全部入り」（Brewfile / apt / winget）だけで、最小セットの概念が無かった。
用途: サーバ/ヘッドレス向けの macOS に、最低限必要なアプリだけを宣言的に定義して導入したい。

## Decision / Finding（決定・発見）

- **単一のコア定義ファイル** `deps/core.txt` を唯一の情報源にする。
  - 形式: `<manager> <name>`（`manager` = `brew` / `cask`）。`#` コメント・空行は無視。
  - 現状は **macOS のみ**。Linux / Windows 用の処理は意図的に作らない。
- 用途は「サーバ/ヘッドレス向け最小 CLI」。アプリは dotfiles のシェル設定
  （`.zshrc` の mise/fzf/bat/ghq/gibo/lazygit/nvim/direnv など）が実際に使うものと、
  ヘッドレス開発の基礎（git/curl/wget/tmux/rg/fd/jq/yq 等）で構成。GUI cask は無し。
  - 収録（19）: git, curl, wget, zsh, bash, tmux, ripgrep, fd, fzf, bat, jq, yq,
    mise, direnv, gh, ghq, gibo, lazygit, neovim
- 導入経路:
  - `make deps-core` = `install-deps.sh --core`
  - `make deps-core-dry` = `install-deps.sh --core --dry-run`（内容表示のみ、変更なし）
  - macOS では `core.txt` から一時 Brewfile を生成し `brew bundle --file=<tmp>`。
  - `bootstrap.sh --deps-core` でも導入可能。既定の `make deps` / `--deps`（全部入り）は不変。
- `deps/check.sh` に core の欠落チェックを追加（基盤層の方針に合わせ **warn**、FAIL にはしない）。
- `docs/dependency-policy.md` に core プロファイルの節と `make deps-core` を追記。

## Verification（検証）

- `bash -n` で install-deps.sh / bootstrap.sh / check.sh の構文 OK。
- `install-deps.sh --core --dry-run` が 19 件の Brewfile を正しく生成（実行なし）。
- `--dry-run` を `--core` 無しで指定 → exit 2（誤用防止）。
- `make help` に deps-core / deps-core-dry を表示。
- `deps/check.sh` が core 19 件を検査（例: brew 未導入の `zsh` を warn）。
- `bootstrap.sh` の空配列展開（bash 3.2 + `set -u`）を安全化（`${arr[@]+...}`）。
